# IoT-Based Autonomous Warehouse Vehicle Management

## About
This repository contains the project files for an Advanced Java project focused on the management and optimization of autonomous warehouse vehicles using IoT technologies. It includes datasets, exploratory data analysis (EDA) notebooks, and the core project logic for tracking, routing, and inventory analysis.

## 🗂 Repository Structure
The repository consists of the following key directories and files:

* **`warehouse_project-main/`**: Contains the core Advanced Java logic and files for the warehouse management system.
* **`RFID_reading_dataset-main/`**: Dataset containing RFID tag readings for inventory tracking and management.
* **`RSSI-Dataset-for-Indoor-Localization-Fingerprinting-master/`**: Dataset used for indoor vehicle localization and mapping using Received Signal Strength Indicator (RSSI) fingerprinting.
* **`ziped dataset/`**: Compressed archive of the project's datasets.
* **`indoor-location-exploratory-data-analysis.ipynb`**: Jupyter Notebook containing exploratory data analysis for the indoor positioning systems.
* **`mega-star-distribution-centre-inventory-analysis.ipynb`**: Jupyter Notebook detailing inventory and distribution center analytics.
* **Datasets (`.csv`)**: 
  * `iot_warehouse_optimization_dataset.csv`
  * `logistics_dataset.csv`
  * `warehouse_iot_dataset.csv`

## 🛠 Tech Stack
* **Languages:** Java (Core Project), Python, Lua
* **Data Analysis:** Jupyter Notebook, Python Data Science Libraries
* **Core Concepts:** Internet of Things (IoT), Indoor Localization (RSSI), RFID, Logistics Optimization, Data Analytics
